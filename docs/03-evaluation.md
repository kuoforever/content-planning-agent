# 验证结果

完整输入、输出和逐步 trace 保存在各场景目录。输入相同的两组实验使用隔离数据库；对照组仅将标准素材费用从 4 调为 7。

- [正常](../examples/normal/)　Mock 估算为 9，生成脚本并保存，共 3 步。
- [报价超限](../examples/overbudget/)　Mock 观察到 12，检索替代素材并重新估算为 8，完成保存，共 5 步。
- [预算缺失](../examples/missing/)　needs_input，工具调用为零。缺截止时间另有参数化测试。
- [保存故障](../examples/failure/)　保存失败，保留脚本和报价。测试查询数据库确认方案数为零。
- [预算不可行](../examples/impossible/)　预算 6，最低方案 8，缺口 2。
- [工期不足](../examples/late/)　可用 60 分钟，经济方案需 90 分钟，缺口 1800 秒。
- [测试运行记录](../examples/pytest.txt)　覆盖独立进程重复提交、请求冲突、强制约束、12 轮上限和 HTTP 工具回传协议。

两组 live 输出记录了配置缺失，真实模型调用数均为零。当前不能据此判断真实模型会如何重规划。具备可用模型后运行 README 中的 live 对照实验，并根据实际动作更新本页。
