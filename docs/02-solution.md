# 调用流程与取舍

CLI 校验输入并查询已保存结果，随后把任务、函数契约及观察结果交给决策器。每轮校验一个工具请求，执行后以对应的 tool_call_id 回传。搜索返回素材，估算返回绑定素材和档位的报价，生成与保存引用同一报价。预算和截止时间由程序检查，生成与保存时重新核对剩余工期。12 轮后停止。模型协议错误、服务异常或配置缺失均导致明确的未完成状态。

两档合成素材各绑定一个脚本档位，脚本生成工具使用本地模板。CLI 将工具轨迹与最终结果输出为 JSON。SQLite 唯一键配合事务实现成功保存的幂等。请求签名包括输入、模式和素材目录，便于发现重用请求 ID 的配置冲突。失败产物随结果导出，无跨进程自动续跑。并发时可能重复估算或生成，持久化方案只有一份。

原生标准库即可展示逐轮决策与状态变化，无需外部服务来模拟业务工具。fixture 使用固定时钟，常规运行在每次可行性检查时读取实际时间。
